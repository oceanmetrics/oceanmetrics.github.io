The rebuilt **marinebon.org** went live on 29 July 2026. It carries a new Methods section, a Network
page with the rotating globe of observing nodes, and one Products catalog that replaces the separate
tool and dataset lists. Python harvesters keep the datasets and papers current from OBIS, GBIF, EDI
and ERDDAP, and scientists add content through GitHub issue forms without touching Git.

This Ocean Metrics site runs on the same architecture.
