How unsubscribing works

  • Every alert mail carries the standard one-click unsubscribe: your mail program's Unsubscribe button ends every alert to this address at once, with no page in between.
  • The Unsubscribe link in a mail's footer opens this page with a button to press. A link never changes anything by itself, so a mail scanner that opens it unsubscribes no one.
  • Delete removes one alert. Unsubscribe from all ends every alert and keeps only a one-way fingerprint of the address, so it is not mailed again unless you subscribe anew.
